# Community Health and Nutrition Improvement Project (CHNIP)

## M&E / MEAL Indicator Tracking System

### Project Overview

The Community Health and Nutrition Improvement Project (CHNIP) is a simulated 12-month community health and nutrition project designed to demonstrate practical Monitoring, Evaluation, Accountability and Learning (MEAL) skills.

The project focuses on tracking program performance, assessing indicator achievement, identifying data-quality issues, and using evidence to support program decision-making.

### Project Objective

The overall objective is to improve access to and utilization of basic health and nutrition services among vulnerable community members.

The project tracks activities and results across five communities during the 2026 implementation period.

---

## Project Objectives

The project aims to:

1. Increase access to community-based health and nutrition services.
2. Improve early identification of children at risk of malnutrition.
3. Strengthen health and nutrition education at community level.
4. Improve completion of referrals to appropriate services.
5. Strengthen the capacity of community health volunteers.
6. Establish a systematic approach to monitoring program performance and data quality.

## MEAL Workflow

The project follows a simplified MEAL data cycle:

```text
Data Collection
      ↓
Data Cleaning
      ↓
Data Quality Assessment
      ↓
Indicator Calculation
      ↓
Performance Analysis
      ↓
Dashboard & Visualization
      ↓
Findings & Recommendations
      ↓
Program Decision-Making
```

---

## Indicator Performance

Indicator performance is calculated using:

**Achievement (%) = Actual Result ÷ Target × 100**

Performance is classified using the following thresholds:

| Achievement | Performance Status |
| ----------: | ------------------ |
|       ≥ 90% | On Track           |
|      70–89% | Needs Attention    |
|       < 70% | Off Track          |

Indicators with missing or questionable data are flagged for further verification rather than automatically interpreted as program performance.

---

## Data Quality Assessment

The project assesses data quality across five key dimensions:

* **Completeness** – whether all required data are available.
* **Accuracy** – whether reported figures agree with source documents.
* **Timeliness** – whether reports are submitted within the required reporting period.
* **Consistency** – whether figures remain consistent across reporting tools.
* **Validity** – whether reported data conform to the approved indicator definition.

Examples of data-quality issues incorporated into the project include:

* Missing values
* Duplicate records
* Inconsistent community names
* Indicator naming errors
* Disaggregation inconsistencies
* Reporting delays
* Source-document discrepancies

## Disaggregation

Where applicable, indicators are disaggregated by:

* Sex
* Age group
* Community
* Beneficiary category
* Service type

This allows program performance to be examined beyond aggregate totals.

This project demonstrates practical understanding of how monitoring data can move from routine data collection to actionable program intelligence.
